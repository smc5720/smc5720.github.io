§01Intro

2018년부터 백엔드를 만들고 있습니다. 결제와 정산처럼 틀리면 곧바로 드러나는 영역을 오래 다뤘고, 지금은 사내 플랫폼 팀에서 API 게이트웨이와 배치 파이프라인을 봅니다.

이 블로그는 원래 뉴스 스크랩을 자동화해 보려고 만들었습니다. 매일 도는 수집 배치가 뉴스를 쌓고, 그중 다시 읽을 만한 주제에만 직접 글을 붙입니다. 그래서 글 수는 많지만 제가 쓴 글은 적습니다.

읽는 사람을 특정하지 않고 씁니다. 대신 6개월 뒤의 제가 다시 찾아올 수 있도록, 판단의 근거와 당시 조건을 같이 적어 두려고 합니다.

01 쟁점은 두 가지다 #

국회 산업통상자원중소벤처기업위원회는 특별법 심사 과정에서 연구개발 인력에 한정한 근로시간 예외 조항을 별도 논의 안건으로 분리했다. 지난 회의 회의록에는 적용 대상을 어디까지 볼 것인가에 대한 이견이 그대로 남아 있다.

적용 대상

현행 초안은 예외 적용을 전담 연구직으로 제한한다. 생산기술 직군 포함 여부가 다음 회의의 첫 안건이다.

  • 전담 연구직 — 초안에 포함
  • 생산기술 직군 — 미정
    • 공정 개발 인력
    • 설비 엔지니어
  • 파견·용역 인력 — 제외

적용 대상을 넓히면 법안이 통과되지 않고, 좁히면 현장에서 쓸 수 없다.

— 위원회 관계자

일몰 기한

  1. 3년안 — 여당 제시
  2. 5년안 — 업계 요구
  3. 기한 없는 상시 적용 — 논의 대상에서 제외

// 한글은 분당 500자 기준
export function readingTime(text: string) {
const chars = text.replace(/\s+/g, "").length;
return Math.max(1, Math.round(chars / 500));
}
