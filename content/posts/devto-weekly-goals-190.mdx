## 개요

Dev.to에 190번째 주간 목표 스레드가 올라왔다. 작성자 Chris Jarvis는 매주 같은 형식으로 자신의 목표를 공개하고, 지난주 목표를 얼마나 지켰는지 체크 표시로 정리한다. 이번 회차는 미국 학생들의 여름방학 마지막 주에 맞물렸다.

Jarvis는 이번 주가 너무 바빴던 탓에 Dev.to의 새 프론트엔드 챌린지 공지를 놓쳤다고 적었다.

## 이번 주 목표

스레드는 세 가지 질문으로 시작한다. 이번 주에 무엇을 만들 것인지, 무엇을 배우고 싶은지, 어떤 행사에 참석할 것인지다.

![펜이 놓인 플래너](https://images.pexels.com/photos/7439133/pexels-photo-7439133.jpeg?auto=compress&cs=tinysrgb&h=650&w=940)

Jarvis가 이번 주에 적어둔 목표는 이렇다.

**구직 활동**
- 네트워킹
- 지원서 제출

**프로젝트 작업**
- 사이드 프로젝트용 콘텐츠 제작
- 개인 프로젝트 진행
- Copilot과 Claude 더 익히기
- CSS Battles 2~3개 완료
- Dev.to 프론트엔드 챌린지 참여
- 업데이트된 CodePen 살펴보기, 가능하면 블로그로 정리

**그 외**
- 블로그 글 쓰기
- 행사 참석: Python Nash 온라인 밋업, 하이브리드 데이터 밋업, 목요일 Virtual Coffee
- Virtual Coffee(VC) 슬랙에 목표 설정 스레드 열기

## 지난주 결산

이 스레드의 핵심은 목표 나열이 아니라 회고 쪽에 있다. Jarvis는 완료(✅), 진행 중(🚧), 미달(❌) 세 가지 상태로 지난주를 정리했다.

완료 표시가 붙은 건 네트워킹, 사이드 프로젝트 콘텐츠 제작, 블로그 글, 금요일 Virtual Coffee 런치 앤 런, VC 슬랙 목표 설정 스레드다.

지원서 제출과 Copilot·Claude 학습은 아직 진행 중으로 남겼다.

달성하지 못한 항목도 그대로 공개했다. CSS Battles는 2~3개를 목표로 했지만 하나만 풀었고, CodePen 업데이트 확인은 손대지 못했다. 목요일 Virtual Coffee도 빠졌는데, 오전에 개학 준비 예약이 있었고 주말 인파를 피해 미리 쇼핑을 다녀오려 했다는 이유를 덧붙였다. 금요일부터 신학기 용품 면세 주말이 시작되기 때문이다.

## 커버 이미지와 마무리

Jarvis는 커버 이미지가 직접 촬영한 레고 사진이라고 밝혔다. 데스크톱 컴퓨터 앞에 앉아 일하는 대피 덕이고, 배경에는 작은 고무 오리가 놓여 있다.

글 끝에는 회차마다 빠지지 않는 서명 같은 커밋 메시지가 붙는다.

```html
-$JarvisScript git commit -m "edition 190"
```

그리고 스레드는 처음과 똑같은 질문을 독자에게 던지며 끝난다. 이번 주에 무엇을 만들 것인지, 무엇을 배우고 싶은지, 어떤 행사에 참석할 것인지.
