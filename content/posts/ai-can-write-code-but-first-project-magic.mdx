## 개요

Dev.to 사용자 Sᴛᴀʀ⭐가 생애 첫 프로젝트를 공개했습니다. 인도의 모든 주(state)를 한 페이지에 소개하는 웹 페이지입니다.

작성자는 글 첫머리에서 솔직하게 털어놓습니다. 첫 프로젝트라 완벽하지 않고, 버그도 꽤 있을 거라고요. 요즘은 AI에게 부탁하면 HTML 파일 하나쯤은 순식간에 나온다는 것도 잘 압니다. 그런데도 직접 만드는 쪽을 택했습니다.

## 본문

### 복사·붙여넣기로는 얻을 수 없는 것

AI에게 요청하면 코드 전체가 눈앞에 바로 펼쳐집니다. 작성자도 그건 인정합니다. 다만 초보자라면 오류와 씨름하며 코드를 직접 써 봐야 배우는 게 있고, 그건 복사해서 붙여넣는 것만으로는 절대 얻을 수 없다고 말합니다.

그렇다고 AI를 아예 쓰지 않은 것도 아닙니다. 작성자는 이 프로젝트를 "내 머리와 약간의 AI"로 만들었다고 밝혔습니다. 주도권은 자기가 쥐고, AI는 보조로만 쓴 셈입니다.

### 결과물: 인도의 모든 주를 담은 페이지

완성한 페이지는 GitHub Pages에 올려 두었고, 누구나 들어가 볼 수 있습니다.

[데모 페이지 보기 →](https://stargshs.github.io/India.github.io/)

주제를 고른 이유도 덧붙였습니다. 작성자는 자기 나라만 좋아하는 게 아니라 세계 모든 나라를 깊이 존중한다고 말합니다. 여러 문화와 장소를 알아 가는 걸 좋아하는데, 그 시작으로 사랑하는 고국 인도의 모든 주를 소개해 보고 싶었다고 합니다.

### 사용한 기술

- **HTML & CSS**
- **JavaScript** — 작성자 표현으로는 "아직 배우는 중이고, 하나씩 적용해 보는 단계"

프레임워크나 빌드 도구 없이 웹의 기본 세 가지만으로 만든 프로젝트입니다.
