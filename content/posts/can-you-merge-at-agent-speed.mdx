## 개요

해커톤 운영 단체 Major League Hacking(MLH)이 **Entire**와 1년짜리 파트너십을 맺었습니다. Entire는 전 GitHub CEO 토마스 돔케(Thomas Dohmke)가 세운 회사로, 에이전트와 사람이 함께 일하는 환경을 전제로 만든 Git 포지(Git forge)를 내놓았습니다.

두 회사는 앞으로 12개월 동안 해커톤 상금, DEV 챌린지, 커뮤니티 피드백 프로그램을 함께 운영합니다. MLH와 DEV 커뮤니티 개발자들이 코딩 에이전트가 코드를 만들어내는 속도에 맞춰 변경 사항을 머지하고, AI로 개발한 과정을 기록하고 공유하는 경험을 직접 해보게 하자는 취지입니다.

## 왜 지금 새로운 Git 포지인가

MLH는 해커톤 장면 하나로 문제를 설명합니다. 대회 14시간째, 에이전트 여러 개를 돌리고 접근법을 세 번 바꾼 끝에 드디어 답을 찾았습니다. 이제 올리기만 하면 됩니다.

그런데 코드는 사람이 쓴 코드를 사람이 리뷰하던 시절에 만든 풀 리퀘스트 흐름을 그대로 거칩니다. 세션이 끝나면 에이전트가 프로젝트에 대해 알게 된 내용도 함께 사라지고, 다음 프롬프트는 처음부터 다시 시작합니다. MLH는 지금의 Git 포지가 사람 속도에 맞춘 작업 루프를 위해 만들어졌을 뿐, 에이전트와 협업하는 개발자를 염두에 두지 않았다고 지적합니다.

MLH가 해커톤에 주목하는 이유도 여기에 있습니다. 전 세계 해커톤에는 주말마다 처음 써보는 기술과 아직 실현 방법을 모르는 아이디어를 들고 개발자들이 모입니다. 이것저것 시도하고 망가뜨리면서 서로 배우고, 가끔은 도구를 만든 사람조차 예상하지 못한 사용법을 찾아냅니다. MLH는 개발자들이 지금 에이전트와 일하면서 익히는 습관과 고르는 도구가 앞으로 소프트웨어를 만드는 방식에 영향을 줄 것이라고 보고, 커뮤니티가 그 변화에 끌려가지 않고 직접 방향을 잡는 데 참여하길 바란다고 밝혔습니다.

## Entire는 무엇이 다른가

Entire는 10월 26일, 에이전트-인간 협업 전용 Git 포지를 처음 공개했습니다. 핵심 기능은 다음과 같습니다.

- **Trails** — diff를 보며 코드 변경을 검토하던 기존 풀 리퀘스트 방식 대신, 항공기 조종사의 헤드업 디스플레이 같은 화면을 보여줍니다. 코드를 푸시할 때마다 직접 설정한 자동 평가(eval)를 에이전트가 채점합니다.
- **분산 Git 호스팅** — Git과 호환되는 새 소스 컨트롤 서버 위에서 동작합니다. Entire는 푸시 속도가 GitHub보다 최대 89배, Cursor Origin보다 6배 빠르다고 밝혔습니다. 저장소를 여러 지역에 복제할 수 있어 데이터 레지던시 요건을 맞추고 에이전트가 만드는 대량 트래픽에도 대응합니다.
- **Continuous Memory** — 세션과 프롬프트를 Git 저장소에 동기화하고, 코딩 에이전트가 언제든 그 데이터를 검색해 쓸 수 있게 합니다. 코드베이스의 구조를 지도처럼 그려주는 **Graph**, 지난 세션을 에이전트가 조회할 수 있는 기억으로 바꾸는 **Brain**이 여기에 포함됩니다.

여기에 오픈소스 Entire CLI가 제공하는 **Sessions**가 더해집니다. 에이전트 세션을 커밋과 연결된 체크포인트로 저장하기 때문에, 팀원들이 각 변경 뒤에 어떤 프롬프트와 판단이 있었는지 확인할 수 있습니다.

시간에 쫓기는 해커톤 팀 입장에서 보면 이점은 분명합니다. 에이전트가 쓴 코드를 빠르게 파악해 그만큼 빨리 머지할 수 있고, 에이전트에게 맥락을 다시 설명하는 시간과 토큰 낭비가 줄어듭니다. 그동안 데모로 보여주기 어려웠던 "프로젝트 뒤의 사고 과정"도 보여줄 수 있게 됩니다.

## MLH와 Entire가 함께 하는 일

### 신규 상금 'Best Use of Entire'

북미·유럽·아시아의 MLH 해커톤 150곳에서 AI 워크플로를 가장 잘 짠 팀에게 주는 상이 새로 생깁니다. 참가자는 Entire 기능을 최대한 폭넓게 쓰는 것이 좋습니다.

- Sessions로 팀원과 에이전트에게 맥락 넘기기
- Graph로 코드베이스를 파악하고 토큰 사용량 줄이기
- Brain으로 에이전트가 과거 결정을 기억하게 하기
- Trails로 에이전트에게 작업을 맡기고 결과 검토하기

심사 기준은 매끄러운 사람-AI 협업, 깔끔한 코드 히스토리, 측정 가능한 토큰 효율입니다. 우승 팀은 미니 휴대용 프로젝터를 받고, 현장의 MLH 스태프가 초기 설정을 도와줍니다.

### DEV 챌린지 2건

36시간짜리 주말 대회에 모든 아이디어가 들어맞지는 않습니다. Entire는 DEV 챌린지 두 개를 후원합니다. 참가자는 자기 속도에 맞춰 Entire 도구를 써보고, 무언가를 만들고, 배운 점을 글로 남기면 됩니다. 주말 데모와 달리 글은 남아서 다음 개발자의 학습 자료가 됩니다. 주제와 일정, 상금은 추후 공개합니다.

### 도구 개발팀과 직접 소통하는 채널

MLH는 해커톤을 좋은 스트레스 테스트로 봅니다. 주말 안에 결과물을 내야 하니 도구가 도움이 되는지 걸림돌인지 금방 드러나기 때문입니다. MLH는 커뮤니티 멤버들과 함께 Entire의 도구와 문서를 테스트하고, 불편한 점을 찾아 Entire 팀에 바로 전달할 계획입니다.

### 이미 시작된 협업

이번 파트너십이 처음 함께하는 일은 아닙니다. 토마스 돔케는 9월 HackGT에서 기조연설을 했고, Entire는 Hacktoberfest 2026에도 참여했습니다. 이때 Entire 팀이 DEV에서 커뮤니티와 라이브로 소통했고, Hacktoberfest Open-Source AI DEV Challenges에서는 해커들이 Entire 상품을 받아 갔습니다.

## 양사 대표의 말

MLH 공동창업자이자 CEO인 마이크 스위프트(Mike Swift)는 Entire가 처음부터 MLH 커뮤니티와 잘 맞을 것이라 생각했다고 말했습니다. 해커톤에서는 주말 하루이틀 만에 아이디어를 실물로 만들어야 하고 에이전트도 그 속도를 따라와야 하는데, Entire는 그런 속도에 맞춰 만들어졌으면서도 코드 뒤의 판단을 잃지 않고 남긴다는 설명입니다.

그는 이미 Entire 위에서 만든 사례도 소개했습니다. 압둘 와시(Abdul Wasih)가 만든 모의 면접 도구 **Viva**는 사용자의 Entire 세션을 읽어 AI가 작성한 코드를 찾아낸 뒤, 그 코드에 대해 질문을 던집니다. 스위프트는 "무엇을 출시했는지뿐 아니라 소프트웨어를 어떻게 만들었는지 기록하는 일이 AI 코딩에서 기본 조건(table stakes)이 될 것"이라고 말했습니다.

Entire CEO 토마스 돔케는 "많은 개발자가 해커톤에서 첫발을 내딛는다"며 MLH가 교실이나 사무실 밖의 '제3의 공간'에서 커뮤니티를 만나고 최신 기술을 직접 다뤄볼 기회를 준다고 평가했습니다. 또 지금 세대 개발자 중 상당수가 이미 에이전트를 자연스럽게 다루는 "에이전트 네이티브(agent natives)"이며, 이들이 사람과 에이전트가 함께 소프트웨어를 만드는 방식의 기준을 세울 것이라고 덧붙였습니다.

MLH는 글을 이렇게 마무리했습니다. "여러분이 무엇을 만들지 기대됩니다. 이번에는 어떻게 거기까지 갔는지도 조금 더 볼 수 있을 것 같네요."
