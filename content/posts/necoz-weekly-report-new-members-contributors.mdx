## 개요

고양이와 UFO를 콘셉트로 한 오픈소스 커뮤니티 **Necoz**가 첫 주간 리포트를 냈습니다. 지난주 DEV에 조직 페이지를 열었는데, 일주일 만에 멤버 28명이 들어왔다고 합니다. Necoz는 멤버를 '고양이'라고 부릅니다.

운영자 nyaomaru는 이번 리포트가 첫 회인 만큼 이번 주 이전의 기여도 함께 정리했습니다. 지금까지 **기여자 35명이 여러 프로젝트에서 PR 71건을 병합했습니다.** 앞으로는 매주 일요일마다 새 멤버와 기여자, 이슈, 글 소식을 묶어 올릴 예정입니다.

[Necoz DEV 조직 페이지 보기 →](https://dev.to/necoz)

## 본문

### 일주일 만에 멤버 28명

DEV에서는 글 하나에 멘션을 10개까지만 달 수 있습니다. 그래서 운영자는 새 멤버 28명을 멘션 대신 프로필 링크로 하나하나 소개했습니다. 명단에는 이후 '이달의 고양이'로 뽑힌 johnnylemonny를 비롯해 hanzla, star123, leob, francistrdev 등이 있습니다.

운영자는 이렇게 모인 멤버들과 함께 "물밑에서 무언가를 준비하고 있다"고만 밝히고 자세한 내용은 공개하지 않았습니다.

### 프로젝트별 기여 현황

리포트는 프로젝트마다 기여자와 병합된 PR을 정리했습니다.

**🧩 is-kit — TypeScript 런타임 타입 검증 라이브러리**

[GitHub 저장소 보기 →](https://github.com/necoz-oss/is-kit)

기여자 16명이 테스트와 문서를 주로 손봤습니다. 기능 쪽 수정으로는 `oneOfValues`의 리터럴 타입 좁히기(narrowing) 수정([#400](https://github.com/necoz-oss/is-kit/pull/400))과 `isPlainObject` 엣지 케이스 수정([#406](https://github.com/necoz-oss/is-kit/pull/406))이 들어갔습니다. 그 밖에 `oneOf`·`mapOf`·배열 가드의 단락 평가(short-circuit) 테스트, 지연 predicate 캐싱 테스트, 희소 배열 관련 테스트를 보강했고 `safeParse`·`isNumber` 문서도 다듬었습니다. 기여자 tylrcc는 혼자 PR 5건을 병합했습니다.

**🤖 changelog-bot — AI로 체인지로그를 만드는 도구**

[GitHub 저장소 보기 →](https://github.com/necoz-oss/changelog-bot)

기여자가 가장 많이 몰린 프로젝트입니다. 이번 주에 정리된 내용은 아래와 같습니다.

- 체인지로그 생성 시 릴리스 버전 처리 수정([#251](https://github.com/necoz-oss/changelog-bot/pull/251))
- 중복 체인지로그 항목 처리 수정([#324](https://github.com/necoz-oss/changelog-bot/pull/324))
- JSON 스키마 지원 추가([#288](https://github.com/necoz-oss/changelog-bot/pull/288))
- Jest 커버리지 스크립트 추가([#299](https://github.com/necoz-oss/changelog-bot/pull/299))
- CLI 오류 메시지 개선, 저장소 설정 검증 강화

기여자 dbdefault는 PR 5건을 병합했습니다. 런타임 검증 코드를 is-kit predicate로 단순하게 바꿨고, 펜스 코드 블록 안에서 PR 링크가 잘못 걸리던 문제도 고쳤습니다. 같은 조직의 라이브러리를 서로 가져다 쓰는 사례입니다.

**🦀 type-tune — 공유 TypeScript 타입을 정리하는 Rust CLI**

[GitHub 저장소 보기 →](https://github.com/necoz-oss/type-tune)

ViviBeri가 barrel re-export를 거친 별칭(aliased) 혼합 import 테스트를 보강했습니다([#23](https://github.com/necoz-oss/type-tune/pull/23)).

**🌐 Necoz 웹사이트**

[GitHub 저장소 보기 →](https://github.com/nyaomaru/necoz)

effessdev가 모바일 레이아웃은 그대로 두고 데스크톱에서 텍스트 간격과 줄바꿈이 어긋나던 문제를 고쳤습니다([#23](https://github.com/nyaomaru/necoz/pull/23)).

### 토론에서 시작된 새 프로젝트 safe-paste

커뮤니티 토론에서 나온 아이디어 하나가 **safe-paste**라는 새 오픈소스 프로젝트가 됐습니다. 민감한 정보를 실수로 붙여넣지 않도록 막아 주는 작은 도구입니다. 아직 개발 초기 단계라 함께 만들 사람을 찾고 있습니다.

[safe-paste 저장소 보기 →](https://github.com/necoz-oss/safe-paste)

새 아이디어나 프로젝트 제안은 [GitHub Discussions](https://github.com/orgs/necoz-oss/discussions)에 올리면 됩니다.

### 첫 번째 '이달의 고양이'

첫 'Cat of the Necoz'로는 **johnnylemonny**(John)가 뽑혔습니다. John은 changelog-bot에서 WHY 추출과 평가, GitHub 메타데이터 처리, 출력 전달, Grok 지원, 보안, 크로스 플랫폼 호환성까지 폭넓게 기여했습니다.

[johnnylemonny GitHub 프로필 보기 →](https://github.com/johnnylemonny)

- [#18 — 조건부·매핑·제네릭 타입 이동의 안전성 검증](https://github.com/necoz-oss/type-tune/issues/18)
- [#32 — 타입 이동으로 생기는 순환 의존성 감지](https://github.com/necoz-oss/type-tune/issues/32)

[type-tune 이슈 전체 보기 →](https://github.com/necoz-oss/type-tune/issues)
