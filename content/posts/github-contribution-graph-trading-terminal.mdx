## 개요

GitHub 프로필의 초록색 잔디는 사실 히트맵입니다. 개발자 Hanzla Baig는 이걸 차트로 보고 싶었고, 그래서 **`gh-trading-terminal`**을 만들었습니다. 실제 기여 기록을 TradingView나 블룸버그 터미널처럼 생긴 화면으로 그려주는 GitHub Action입니다.

결과물은 **SVG 파일 하나**입니다. 외부 리소스를 하나도 쓰지 않아서 프로필 README에 그대로 넣으면 됩니다. 저장소는 [hanzlabaig-dev/gh-trading-terminal](https://github.com/hanzlabaig-dev/gh-trading-terminal)에 있고 MIT 라이선스입니다. Node 18.3 이상에서 돌아가며 **의존성은 0개**입니다.

![gh-trading-terminal preview in the dark theme](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/6nsj619d8wnbznbin2ob.png)
*미리보기 이미지는 샘플 데이터로 만들었습니다. 실제로 쓰면 본인의 기여 기록이 들어갑니다.*

## 터미널에 들어가는 패널

모든 패널은 순수 SVG로 그리고, 어떤 패널을 보여줄지는 직접 고를 수 있습니다.

| 패널 | 내용 | `show` 이름 |
| :--- | :--- | :---: |
| 캔들스틱 | 하루에 캔들 하나. 오늘(UTC 기준) 캔들은 깜빡이며 표시 | *(항상 표시)* |
| 거래량 | 차트 아래에 일별 기여 수 그대로 표시 | `volume` |
| 분석 | 총합, 일평균, 활동일 수, 현재·최장 연속 기록, 최고 기록일, 변동성(σ), 샤프 지수, 최대 낙폭, 가장 활발한 요일 등 10개 지표 | `stats` |
| 히트맵 | 최근 26주, 요일 × 주 | `heatmap` |
| 주간 거래량 | 최근 12주와 전주 대비 증감 | `weekly` |
| 월간 종가 | 최근 6개월과 전월 대비 증감 | `monthly` |
| 티커 테이프 | 주요 수치가 흘러가는 띠 | `tape` |
| SMA | 20일 이동평균선 | `sma` |
| 밴드 | 같은 20일 구간의 ±2σ 밴드 | `bands` |

기본값으로는 **`bands`만 빼고 전부** 켜집니다. 밴드까지 보려면 `show: all`로 설정하면 됩니다.

헤더에는 0~1000점짜리 가상 점수인 **Developer Index**가 스파크라인, 깜빡이는 `LIVE` 표시와 함께 나옵니다.

## 서버 없이 세 단계로 설치

### 1. 워크플로 추가

프로필 저장소(`USERNAME/USERNAME`)에 `.github/workflows/terminal.yml` 파일을 만듭니다.

```yaml
name: Update trading terminal
on:
  schedule: [{ cron: '17 */6 * * *' }]
  workflow_dispatch:
permissions:
  contents: write
jobs:
  terminal:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: hanzlabaig-dev/gh-trading-terminal@v1
        with:
          days: 90
          theme: tradingview
          token: ${{ secrets.GH_PAT || secrets.GITHUB_TOKEN }}
```

### 2. 한 번 실행

**Actions** 탭에서 *Update trading terminal*을 선택하고 *Run workflow*를 누릅니다. 실행이 끝나면 아래 두 파일이 렌더링돼 커밋됩니다.

- `assets/terminal-dark.svg`
- `assets/terminal-light.svg`

### 3. README에 넣기

프로필 `README.md`에 아래 블록을 넣으면 보는 사람의 라이트/다크 테마에 맞춰 이미지가 바뀝니다.

```html
<picture>
  <source media="(prefers-color-scheme: light)" srcset="assets/terminal-light.svg">
  <img src="assets/terminal-dark.svg" width="100%" alt="GitHub contribution trading terminal">
</picture>
```

### 비공개 기여도 포함하려면

1. `read:user` 권한으로 토큰을 만듭니다.
2. 저장소 시크릿에 **`GH_PAT`**라는 이름으로 저장합니다.
3. GitHub 프로필 설정에서 **"Private contributions"**를 켭니다.

워크플로에 `secrets.GH_PAT || secrets.GITHUB_TOKEN`이라고 적어둔 이유가 이것입니다. 기본 토큰이 거부되면 `GH_PAT`를 씁니다.

## 입력값과 테마

| 입력 | 기본값 | 설명 |
| :--- | :--- | :--- |
| `username` | 저장소 소유자 | 아무 GitHub 계정 |
| `days` | `90` | 14~730 |
| `theme` / `light-theme` | `tradingview` / `light` | `tradingview`, `bloomberg`, `midnight`, `light` |
| `output-dir` | `assets` | SVG 저장 위치 |
| `show` | `bands` 제외 전체 | `stats,heatmap,weekly,monthly,volume,tape,sma,bands` 또는 `all` |
| `extra-args` | *(비어 있음)* | CLI 플래그 직접 전달. 예: `--colorblind true --hide tape --up #00ff88` |
| `commit` | `true` | 커밋을 직접 관리하려면 `false` |

테마는 네 가지입니다.

| 테마 | 스타일 |
| :--- | :--- |
| `tradingview` | 기본 다크 테마. 남색 배경에 청록/빨강 캔들 |
| `bloomberg` | 검은 배경에 호박색 글자, 초록/빨강 캔들 |
| `midnight` | GitHub 다크 모드 계열 색상 |
| `light` | `terminal-light.svg`의 기본 테마 |

### 색각 이상 모드와 색상 지정

색각 이상 모드를 켜면 캔들 색이 **파랑(상승)과 주황(하락)**으로 바뀝니다.

```yaml
- uses: hanzlabaig-dev/gh-trading-terminal@v1
  with:
    extra-args: "--colorblind true --hide tape --up #00ff88"
```

`extra-args` 값은 **꼭 따옴표로 감싸야** 합니다. YAML에서는 따옴표 없는 ` #`부터 주석으로 처리하기 때문에 `--up #00ff88`이 아무 경고 없이 잘려 나갑니다.

색상 플래그는 `--up`, `--down`, `--bg`가 있습니다. 평활 계수는 `--alpha`로 조정하며 기본값은 `0.5`, 허용 범위는 0.1~0.9입니다.

## 캔들은 어떻게 만들어지나

GitHub은 **하루 단위** 기여 합계만 제공합니다. 그러니 진짜 장중 OHLC 데이터는 존재하지 않습니다. 대신 실제 기여 수를 **정해진 규칙으로 변환해** 캔들을 만듭니다. 지어낸 숫자는 없습니다.

"가격" 역할은 일별 활동량의 지수이동평균(EMA)이 맡습니다.

```text
level(t) = level(t-1) + alpha * (count(t) - level(t-1))
```

이 값으로 캔들을 이렇게 계산합니다.

```text
open  = level(t-1)
close = level(t)
high  = max(open, close, count(t), count(t-1))
low   = min(open, close, count(t), count(t-1))
```

`close >= open`이면, 즉 그날 활동이 이동평균을 넘으면 초록 캔들이고 아니면 빨간 캔들입니다.

몇 가지 세부 처리도 있습니다.

- **거래량**은 하루 기여 수를 그대로 씁니다. 너무 튀는 날은 적당한 축 한계에서 **잘라내고 작은 삼각형으로 표시**합니다. 어느 하루가 폭주해도 차트 전체가 납작해지지 않게 하려는 장치입니다.
- 아직 끝나지 않은 오늘 기여가 0이어도 **연속 기록은 끊기지 않습니다.**
- 오늘(UTC) 캔들은 장이 아직 열려 있다는 의미로 **반투명하게 깜빡입니다.**

### Developer Index 계산법

최근 **28일**을 기준으로 네 가지 요소를 섞어 0~1000점을 냅니다. 가상의 점수지만 계산식은 모두 공개돼 있어 똑같이 재현할 수 있습니다.

| 요소 | 비중 | 계산 방식 |
| :--- | ---: | :--- |
| 활동일 비율 | **35%** | 기간 중 기여가 1건 이상인 날의 비율 |
| 강도 | **25%** | `log(1 + mean) / log(1 + 10)`, 최대 1 |
| 연속 기록 | **20%** | 현재 연속 일수 ÷ 14, 최대 1 |
| 안정성 | **20%** | `1 - min(1, stdDev / mean / 3)` |

여기에 두 지표가 더 붙습니다.

- **샤프 지수**: 일별 기여 수의 평균 ÷ 표준편차
- **최대 낙폭**: Developer Index가 고점에서 저점까지 가장 크게 떨어진 폭

작성자는 이 점수를 "진지한 수학을 쓴 농담"이라고 소개합니다. **투자 조언도 아니고 인사 평가 지표도 아니라는** 설명도 덧붙였습니다.

## 설계를 결정한 제약: GitHub 이미지 프록시

![Shot of computer screen with multicoloured code](https://images.pexels.com/photos/4816921/pexels-photo-4816921.jpeg?auto=compress&cs=tinysrgb&h=650&w=940)
*Photo by [Myburgh Roux](https://www.pexels.com/photo/shot-of-computer-screen-with-multicoloured-code-4816921/) on [Pexels](https://www.pexels.com/photo/shot-of-computer-screen-with-multicoloured-code-4816921/)*

GitHub은 README 이미지를 프록시로 내보내는데, 이 프록시가 **스크립트와 CSS, 웹 폰트를 모두 막습니다.** 그래서 SVG를 이 조건에 맞춰 만들었습니다.

- SVG 기본 속성만 사용 (`<style>`, 스크립트, 외부 참조 없음)
- 시스템 고정폭 폰트 사용
- 애니메이션은 전부 **SMIL**로 처리 (깜빡이는 캔들, `LIVE` 표시, 흐르는 티커 테이프)
- 일반 `<img>` 태그에서 그대로 동작
- 90일 기준 약 **38KB**, 최대치인 730일에서도 약 **100KB** 이하

테스트도 이 조건을 직접 검사합니다. 모든 테마를 렌더링한 뒤 `<script>`, `<style>`, `<foreignObject>`, 외부 URL이 하나도 없는지 확인합니다.

알아두면 좋은 점도 있습니다.

- GraphQL은 한 번에 1년 미만만 조회할 수 있어서, 긴 기간은 **360일 단위로 나눠 가져온 뒤** 날짜 기준으로 중복을 제거합니다.
- GitHub이 이미지를 캐시하기 때문에 변경 사항이 보이기까지 몇 분 걸릴 수 있습니다. SVG 안에 `UPDATED` 시각이 찍혀 있어 언제 갱신됐는지 확인할 수 있습니다.
- Action 봇이 만든 커밋은 **내 기여로 잡히지 않습니다.** 이걸로 잔디를 무한히 채울 수는 없다는 뜻입니다.

## 다른 실행 방법

**CLI**로도 쓸 수 있습니다. Node 18.3 이상이면 되고 의존성은 없습니다.

```bash
git clone https://github.com/hanzlabaig-dev/gh-trading-terminal && cd gh-trading-terminal
npm test
npm run demo        # synthetic data, no token needed
GITHUB_TOKEN=xxx node src/cli.js --user YOU --from 2026-01-01 --to 2026-11-22 --theme bloomberg --out terminal.svg
```

전체 CLI 플래그는 다음과 같습니다.

```text
--user --days --from --to --theme --show --hide
--animate false --colorblind true
--up --down --bg --alpha --demo --out
```

**실시간 URL** 방식도 있습니다. Vercel에 배포하고 `GITHUB_TOKEN`을 설정하면 `api/terminal.js`가 이미지를 1시간 캐시해서 내보냅니다.

```text
https://YOUR-APP.vercel.app/api/terminal?user=YOU&theme=bloomberg&days=120
```

## 테스트와 기여

`npm test`는 Node 내장 테스트 러너로 6개 테스트를 돌립니다. 캔들 계산의 불변 조건, 연속 기록 로직, 모든 테마의 안전한 렌더링, 표시 옵션과 입력값 검증, 분할 GraphQL 조회, Action 진입 스크립트를 검사합니다. CI는 **Node 18, 20, 22**에서 실행합니다.

PR도 받고 있습니다. 작업 위치는 이렇게 나뉩니다.

| 추가하고 싶은 것 | 파일 |
| :--- | :--- |
| 새 테마 | `src/themes.js` |
| 레이아웃 변경 | `src/render.js` |
| 새 지표 | `src/analytics.js` |

PR을 올리기 전에 `npm test`를 먼저 돌려야 합니다. 작성자는 다음에 어떤 패널이나 지표를 추가하면 좋을지 원문 댓글로 의견을 받고 있습니다.
