> **원문:** [전국 곳곳 흐리고 비…강원 북부 '대설 특보' 가능성](https://www.yna.co.kr/view/AKR20261123003400034) — 연합뉴스

## 개요

월요일인 23일에는 전국 곳곳에 비나 눈이 옵니다. 오전에 수도권과 강원 내륙·산지, 충남 북부부터 비가 시작되고, 오후에는 나머지 충청권과 남부지방까지 넓어집니다. 중부지방은 늦은 밤이면 대부분 그칩니다.

강원 북부 내륙과 북부 산지에는 낮까지 시간당 1∼3㎝의 강한 눈이 내릴 수 있어 대설특보가 내려질 가능성도 있습니다.

## 지역별 예보

### 비: 수도권·충청권이 가장 많다

예상 강수량은 아래와 같습니다.

| 지역 | 예상 강수량 |
| --- | --- |
| 서울·인천·경기 북부 | 5∼30㎜ |
| 경기 남부·서해5도 | 5∼20㎜ |
| 강원 내륙·산지 | 5∼20㎜ |
| 강원 동해안 | 5㎜ 안팎 |
| 대전·세종·충남·충북 | 5∼20㎜ |
| 전북·광주·전남 | 5∼10㎜ |
| 대구·경북 | 5∼10㎜ |
| 부산·울산·경남 | 5㎜ 안팎 |
| 제주도 (24일 오전까지) | 5∼20㎜ |

### 눈: 강원 북부 최대 8㎝

강원 북부 내륙·산지에는 3∼8㎝, 강원 중·남부 내륙·산지에는 1∼5㎝의 눈이 쌓이겠습니다. 제주 산지에도 24일 아침까지 1㎝ 미만의 눈이 내립니다.

지난 20일에는 대설주의보가 내려진 전북 정읍시 내장동에서 눈 무게를 못 이긴 나무가 도로로 쓰러져 버스가 오도 가도 못하는 일도 있었습니다. 강원 북부를 지나는 운전자라면 출발 전에 특보 발효 여부를 확인해 두는 편이 좋습니다.

### 기온: 아침 영하권, 낮에는 7∼15도

이날 오전 5시 기온은 서울 0.6도, 인천 3.8도, 강릉 5.8도, 청주 -0.4도, 전주 2.4도, 광주 1.8도, 제주 7.3도, 대구 -2.4도, 부산 4.5도, 울산 0.5도, 창원 1.3도였습니다. 청주와 대구는 영하권에서 하루를 시작했습니다. 낮 기온은 7∼15도까지 오릅니다.
