## 개요

개발자 Mika Flowers는 코딩을 주로 2020년식 200달러짜리 노트북에서 하고, 글은 대부분 2006년형 아이맥에서 씁니다. 둘 다 가족에게 물려받은 기기라 돈은 한 푼도 들지 않았습니다.

글쓴이는 낡은 하드웨어를 다시 쓰는 일을 좋아합니다. OS나 보안 업데이트가 끊겼을 뿐 아직 제 몫을 충분히 하는 기기가 많다고 봅니다. 그래서 기기마다 일을 하나씩 일부러 나눠 맡깁니다. 이 글에서는 각 기기가 무슨 일을 하고 무엇을 못 하는지, 그런데도 왜 계속 쓰는지 정리합니다.

## 본문

### 게이밍 PC도 있다

![mainpc](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/uiwu57vb9osvmlym6ctp.jpeg)

글쓴이에게도 게이밍 PC는 있습니다. 개발 워크스테이션을 겸하고 있어서 코딩도 거기서 합니다. 주로 로컬 모델을 실험하거나, 작업을 여러 개 동시에 돌리거나, 최근에는 Oniria를 디버깅할 때 씁니다.

다만 요즘은 공부하는 시간이 대부분이고, 게임은 여가에만 합니다. 이동 중에 아이디어가 떠오를 때, 여행 중일 때, 아니면 쌓여만 가는 스팀 게임 목록에 한눈팔고 싶지 않을 때 노트북이 제 역할을 합니다.

### 노트북: 2020년식 HP 보급형

글쓴이가 "믿음직한 녀석(ole reliable)"이라고 부르는 기기입니다. 받자마자 Windows를 지우고 Fedora Linux를 설치했고, 무거운 앱과 저장소 몇 개도 걷어냈습니다. 지금은 집중하고 싶을 때 쓰는 미니멀한 코딩 머신입니다. 듀얼 모니터 워크스테이션보다 이 노트북으로 코딩하는 시간이 더 많다고 합니다. 단순함 자체에 끌린다는 게 글쓴이의 설명입니다.

![gal](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/s0pdquud6650cur80d2s.jpeg)

![olereliabe](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/e41tstk9br181yz725i5.png)

사양은 fastfetch에서 로고와 호스트명 줄을 끄고 필요한 항목만 뽑아 확인했습니다.

```bash
fastfetch -c none -l none -s os:host:cpu:gpu:memory:disk
```

- **OS:** Fedora Linux 44 (Workstation Edition)
- **Host:** HP Laptop 15-dy2xxx
- **CPU:** 11세대 Intel Core i3-1125G4 (4코어 8스레드)
- **GPU:** Intel UHD Graphics 내장
- **메모리:** 8GB
- **저장공간:** 256GB

2026년 기준으로 내세울 만한 사양은 아니지만 글쓴이는 개의치 않습니다. 램 8GB로는 앱을 열 개씩 띄울 수 없으니 애초에 그렇게 쓰지 않습니다. 가볍게 관리하면 충분히 따라온다고 합니다.

Fedora를 쓰는 덕에 업데이트도 꾸준히 받습니다. 아이맥은 그렇지 못합니다.

### 아이맥: 2006년, Mac OS X Tiger

글쓰기용 기기는 메모리 2GB짜리 2006년형 Intel 아이맥이고, OS는 Mac OS X Tiger입니다. FocusWriter 정도만 돌리고, 오로지 글쓰기에만 씁니다.

인터넷에도 연결하지 않습니다. Tiger는 보안 업데이트가 끊긴 지 10년이 훌쩍 넘었기 때문에 오프라인으로 두는 편이 안전합니다. 글쓴이는 바로 그게 핵심이라고 말합니다. 들어갈 브라우저도, 알림도, "잠깐 하나만 확인하고"도 없습니다. 이 앞에 앉으면 하려던 일 말고는 할 수 있는 게 없습니다. 다 쓴 글은 USB 메모리에 담아 노트북이나 메인 PC로 옮깁니다.

### 제약이 곧 핵심이다

![man writing on wooden desk](https://images.pexels.com/photos/5124844/pexels-photo-5124844.jpeg?auto=compress&cs=tinysrgb&h=650&w=940)
*Photo by [cottonbro studio](https://www.pexels.com/@cottonbro) on [Pexels](https://www.pexels.com/photo/man-writing-on-wooden-desk-in-classroom-5124844/)*

글쓴이는 제약이 괜히 나쁜 평가를 받는다고 생각합니다. 뭐든 할 수 있는 기기 앞에서는 결국 이것저것 조금씩 하게 됩니다. 탭 하나 열고, 설정 하나 만지고, 밀린 게임 "잠깐" 한 판 하는 식입니다. 반대로 기기가 한두 가지밖에 못 하면 환경을 만지작거리는 대신 실제로 뭔가를 만들게 된다고 합니다.

글쓴이가 말하는 미니멀리즘은 결정할 거리를 줄이는 일입니다. 아이맥에서는 Discord를 열 수가 없으니 열지 말지 고민할 필요도 없습니다. 선택지가 하나 사라질 때마다 주의를 빼앗는 요소도 하나 줄고, 이게 생각보다 빨리 쌓입니다.

제약은 가진 것으로 창의적으로 풀어 보게 만들기도 합니다. 도구가 화려한 기능을 못 하면 단순한 방법을 찾아야 하는데, 결국 내놓을 만한 건 그 단순한 버전인 경우가 많다고 글쓴이는 말합니다.

### 창고에 낡은 기기가 있다면

글쓴이의 제안은 이렇습니다. 요즘 작업을 다 따라가지 못한다고 버리지 말고 일을 딱 하나만 맡기라는 것입니다. 리눅스를 깔든, 오프라인으로 돌리든, 글쓰기 전용이나 집중 코딩 전용으로 만들든, 늘 더 해야지 하면서 미뤄 온 그 일 하나만 하도록 덜어내면 됩니다.

두 기기 모두 새것도 아니고 비싼 물건도 아닙니다. 그래도 정말 일을 끝내야 할 때 가장 먼저 손이 가는 건 이 두 대라고 합니다. 글쓴이는 독자들에게도 두 번째 삶을 준 낡은 기기가 있다면 어떻게 쓰고 있는지 들려 달라며 글을 맺었습니다.
