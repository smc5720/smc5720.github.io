## 개요

Dev.to에서 활동하는 오픈소스 커뮤니티 **Necoz**가 새 공간을 짓기 시작했습니다. Necoz는 멤버를 '고양이', 커뮤니티를 'UFO'에 빗대어 부르는데, 지난주 28명이던 멤버가 일주일 만에 **34명**으로 늘면서 UFO가 비좁아졌다는 게 운영자 nyaomaru의 설명입니다.

새 집은 멤버들이 모여 아이디어를 나누고 함께 무언가를 만드는 공간이 될 예정입니다. 아직 공사 중이라 생김새도, 안에 무엇이 들어갈지도 공개하지 않았습니다. nyaomaru는 "지금은 비밀"이라고만 밝혔습니다.

![nyaomaru house](https://dev-to-uploads.s3.us-east-2.amazonaws.com/uploads/articles/rd9bmvrq8ltm44khti09.gif)

이번 주 소식에는 새 집 예고 말고도 GitHub 프로젝트 4개의 업데이트, 이번 주의 기여자, 새로 열린 이슈, 멤버들이 쓴 글 8편, 다음 주 행사 안내가 함께 실렸습니다.

## 이번 주 프로젝트 업데이트

Necoz의 GitHub 조직(`necoz-oss`)에서는 이번 주 문서 보강과 테스트 강화부터 도구 안전성 개선, 새 기능, 릴리스까지 한꺼번에 이뤄졌습니다.

### is-kit v1.16.6

TypeScript 타입 가드 라이브러리 is-kit가 v1.16.6을 내놨습니다. 이번 릴리스는 API 문서, 런타임 회귀 테스트, 기여자 경험 개선에 집중했습니다.

- [ArnabOPP](https://github.com/ArnabOPP): `oneOf`에서 판별 유니언(discriminated union)이 어떻게 좁혀지는지 문서로 정리 ([#461](https://github.com/necoz-oss/is-kit/pull/461))
- [Lil-Clanky](https://github.com/Lil-Clanky): `tupleOf` 문서 개선, `equalsKey` 엣지 케이스 테스트 보강 ([#460](https://github.com/necoz-oss/is-kit/pull/460), [#458](https://github.com/necoz-oss/is-kit/pull/458))
- [deba2k5](https://github.com/deba2k5): `oneOfValues`의 동등 비교 방식, 입력 형태, 스냅샷 동작 문서화 ([#459](https://github.com/necoz-oss/is-kit/pull/459))
- [atokim4](https://github.com/atokim4): `optional`, `optionalKey`, 그리고 둘을 함께 쓸 때의 차이 정리 ([#457](https://github.com/necoz-oss/is-kit/pull/457))
- [daocuong11](https://github.com/daocuong11): 빌드 문서 갱신, `not` 회귀 테스트 개선, 기여자 체크리스트 보강 ([#456](https://github.com/necoz-oss/is-kit/pull/456), [#455](https://github.com/necoz-oss/is-kit/pull/455), [#447](https://github.com/necoz-oss/is-kit/pull/447))
- [wathsalaggg](https://github.com/wathsalaggg): `hasKey`와 `hasKeys`가 속성 값을 읽지 않는다는 점을 증명하는 테스트 추가 ([#454](https://github.com/necoz-oss/is-kit/pull/454))
- [chirag-gupta7](https://github.com/chirag-gupta7): `guardIn` 전달 테스트와 `equals` 참조 동일성 테스트 커버리지 강화 ([#449](https://github.com/necoz-oss/is-kit/pull/449), [#445](https://github.com/necoz-oss/is-kit/pull/445))
- [agenticsymphony-tech](https://github.com/agenticsymphony-tech): `safeJsonParse`의 에러 경계 명확화 ([#446](https://github.com/necoz-oss/is-kit/pull/446))

운영자는 이번 기여 상당수가 커뮤니티가 가장 중요하게 여기는 방향, 즉 "작은 API를 이해하기 쉽고, 안전하게 쓸 수 있고, 문서가 잘 갖춰진 상태로 만드는 것"과 맞닿아 있다고 강조했습니다.

[is-kit 저장소 보기 →](https://github.com/necoz-oss/is-kit)

### safe-paste

safe-paste는 커뮤니티 토론에서 출발한 브라우저 확장 프로그램입니다. 개발자가 GitHub 이슈 편집기에 민감한 정보를 실수로 붙여 넣는 일을 막는 게 목적입니다.

이번 주에는 [johnnylemonny](https://github.com/johnnylemonny)가 순수 TypeScript로 된 탐지·마스킹(redaction) API를 설계하고, GitHub PAT(Personal Access Token) 탐지 규칙의 초기 버전을 구현했습니다. GitHub 붙여넣기 어댑터 프로토타입도 함께 만들었습니다([#9](https://github.com/necoz-oss/safe-paste/pull/9), [#17](https://github.com/necoz-oss/safe-paste/pull/17), [#12](https://github.com/necoz-oss/safe-paste/pull/12)).

MVP 아키텍처와 개발 환경, UTF-16 기준 입력량 제한(input budget) 설계도 이번 주에 확정됐습니다. 목표는 단순합니다.

> 작업 흐름을 끊지 않으면서, 비밀 정보가 노출되기 전에 개발자에게 경고한다.

불필요한 네트워크 요청은 보내지 않고, 붙여 넣은 내용은 영구 저장하지 않는다는 원칙도 밝혔습니다. 아직 개발 중이고 안전성 작업이 더 남아 있습니다.

[safe-paste 저장소 보기 →](https://github.com/necoz-oss/safe-paste)

이번 주 'Cat of the Necoz'로는 @star123([GitHub](https://github.com/stargshs))이 뽑혔습니다.

Star는 **Necoz Planet 시리즈**를 연재하고 있습니다. 고양이, UFO, Necoz 행성을 배경으로 한 짧은 이야기에 Python 기초를 녹여 낸 시리즈입니다. 이번 주에는 DEV의 기반 오픈소스 프로젝트인 Forem에 첫 이슈를 올리며 오픈소스 기여도 처음 시작했습니다. 운영자는 커뮤니티에 창의성과 호기심을 불어넣어 준 Star에게 고마움을 전했습니다.

## 멤버들이 쓴 글 8편

이번 주에는 Necoz 이름으로 글 8편이 올라왔습니다. 주제는 Rust, C++, Python, 웹 스크래핑, 오픈소스까지 다양했습니다.

- **Star, "The Function Factory of Necoz"**: 고양이 로봇 공장 이야기로 Python 함수와 코드 재사용을 설명합니다. [글 보기 →](https://dev.to/necoz/the-function-factory-of-necoz-learning-python-functions-2ikd)
- **Dev Stack Hub, "Geo-Targeted Web Scraping with Proxies"**: 같은 사이트가 접속 지역마다 다른 가격·언어·상품을 보여 주는 이유부터 시작해, 국가·도시 단위 프록시와 위치 신호를 다룹니다. Python과 Playwright 예제도 실었습니다. [글 보기 →](https://dev.to/necoz/geo-targeted-web-scraping-with-proxies-country-city-level-guide-3446)
- **Star, "Say Hello in Your Language!"**: 전 세계 개발자에게 자기 언어로 인사를 남겨 달라고 제안한 글입니다. 일본에 있는 운영자는 "곤니치와"로 화답했습니다. [글 보기 →](https://dev.to/necoz/say-hello-in-your-language-4ckf)
- **Star, "My First GitHub Issue!"**: 첫 GitHub 이슈이자 Forem에 처음 올린 이슈 경험을 공유했습니다. [글 보기 →](https://dev.to/necoz/my-first-github-issue-my-first-forem-devto-issue-5eap)

*Photo by . Shaahy on [Pexels](https://www.pexels.com/photo/modern-architectural-design-in-the-maldives-39783872/)*

다음 주 일요일에는 Necoz의 첫 **OSS 포틀럭 파티**가 열립니다. 각자 음식을 하나씩 들고 오는 포틀럭처럼, 참가자가 소개하고 싶은 오픈소스 프로젝트를 하나씩 가져오는 행사입니다.

직접 만든 프로젝트든, 다른 사람이 만든 프로젝트든, 이제 막 만들기 시작한 프로젝트든 상관없습니다. 규칙은 "한 사람당 OSS 하나(ONE CAT, ONE OSS)"입니다. 몰랐던 프로젝트를 발견하거나, 다음 아이디어를 얻거나, 새로운 기여처를 찾는 자리가 되길 바란다고 운영자는 밝혔습니다.

커뮤니티에 함께하고 싶다면 원문에 댓글을 남겨 달라고 합니다.
